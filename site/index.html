打开 RAW，看看里面

基于 Tauri 的极简轻量化 RAW 图像查看器。
随处携带，本地执行，开门见山。

下载 Windows x64 EXE从 GitHub 获取最新版本 ↓

eRAW 面向 Windows，用于浏览 RAW 图像、检查像素和统计信息，也可以在需要时进行 Remosaic、Demosaic 或格式导出。

文件始终在本地处理。想进一步了解数据解释、算法和边界条件时，可以通过帮助菜单或 F1 打开内置技术手册。

  • 平台Windows x64
  • 许可GPL-3.0-or-later
  • 数据本地处理，无遥测
