01

CAPABILITIES

从文件布局到像素结论，
保持每一步都可解释。

eRAW 不猜测未知格式。描述符明确约定字节如何成为坐标与 DN，界面则帮助你逐层验证这些约定。

01 / DATA LAYOUT

把字节布局说清楚

配置尺寸、Packing、位深、字节序、有效位位置、文件头偏移以及行/帧 stride 与对齐。

  • Unpacked 8 / 16
  • MIPI RAW10 / 12 / 14
  • 多帧与不完整数据诊断

02 / CFA

验证颜色站点

支持 Mono、四种 Bayer 和四种 Quad CFA 排列，让 Phase 与裁剪后的空间语义保持明确。

03 / INSPECTION

检查每一个 DN

缩放、平移、像素网格、坐标定位及原始/重建通道读数共同服务于局部诊断。

04 / STATISTICS

在 L0 上做统计

以包含式 ROI 统计原始 CFA DN，查看直方图、水平/垂直 Profile、均值、方差与百分位数。

05 / EXPORT

安全地转换与导出

导出原始 CFA、Remosaic Bayer 或 Demosaic RGB48。严格检查裁剪、目标格式、溢出和源文件覆盖风险。

冻结快照→严格校验→临时写入→原子替换
02

WORKFLOW

一条面向工程诊断的
清晰路径。

先确认解释字节的契约，再逐步进入空间、处理和统计结论，避免被“看起来像图像”的结果误导。

  1. 01
    DESCRIBE

    描述数据

    输入尺寸、Packing、位深、offset 与 stride。

    bytes → DN
  2. 02
    VALIDATE

    验证布局

    从 RAW 强度与帧连续性检查地址计算。

    (x, y, frame)
  3. 03
    INTERPRET

    解释 CFA

    确认排列、Phase 与颜色站点是否符合预期。

    site(x, y)
  4. 04
    ANALYZE

    处理与分析

    选择 Remosaic、Demosaic、ROI 与统计视图。

    result + evidence
  5. 05
    EXPORT

    生成结果

    冻结源数据和参数，以严格路径安全写出。

    deterministic output
03

TECHNICAL METHOD

算法服务于诊断，
而不是掩盖数据。

显示与重建方法保持克制，并在技术手册中给出公式、有效样本条件和边界行为。

QUAD CFA → BAYER

Remosaic

支持 4×4 Quad CFA 的确定性重排，以及面向缺失或非整数位置的同色双线性重建。

vsrc = block + permutation(local) − phase
RGB

CFA → RGB

Demosaic

当前使用局部 3×3 邻域的双线性方法；原站点值保持不变，只从有效同色邻点重建缺失分量。

Cc(x,y) = mean(valid neighbors of c)

RAW L0 EVIDENCE

统计与图表

统计摘要先在完整有效样本上计算；图表仅对渲染点进行有界聚合，不改变均值、方差和百分位结论。

σ² = M₂ / n · Qp from histogram rank
