Open RAW. See what's inside.

A minimal, lightweight RAW image viewer built with Tauri.
Take it anywhere. Run locally. Get straight to the point.

Download Windows x64 EXEGet the latest release from GitHub ↓

eRAW runs on Windows and helps you browse RAW images, inspect pixels and statistics, and perform Remosaic, Demosaic, or format export when needed.

Files stay on your computer. For data interpretation, algorithms, and boundary conditions, open the built-in technical manual from the Help menu or press F1.
