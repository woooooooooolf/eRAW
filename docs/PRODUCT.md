# 产品定位与设计决策

## 核心定位

eRAW 面向 SoC Bring-up 和图像传感器适配工作，目标是以舒适、直接、可容错的方式查看传感器 RAW 输出，并完成确定性的格式转储。

它不是照片级 RAW 编辑器，不承担降噪、锐化、坏点校正、颜色校正或其他图像质量优化。预览首先回答“原始数据是什么样”，而不是“怎样让照片更好看”。

## 设计原则

- **忠实**：RAW 强度与 CFA 点阵保留原始 DN 和阵列结构。
- **容错**：查看路径尽量显示可读取内容，并通过诊断提示异常。
- **严格导出**：导出前显式校验所有参数，不沿用预览的试错容忍策略。
- **性能优先**：允许使用更多内存换取大图浏览和交互响应。
- **画布优先**：常驻界面只保留高频操作；诊断等低频内容使用覆盖层。
- **状态可解释**：参数、帧、处理模式和导出来源都有明确快照或世代语义。

## 显示模式

| 来源 CFA | 可用显示 | 处理关系 |
| --- | --- | --- |
| MONO | RAW 强度 | 不显示 CFA、Remosaic、Demosaic |
| 标准 Bayer | RAW 强度、CFA 点阵、Demosaic、RGB 通道 | Demosaic 直接基于 Bayer |
| Quad CFA | RAW 强度、CFA 点阵、Remosaic、Demosaic、RGB 通道 | Demosaic 隐式基于当前 Remosaic 结果 |

当前 Demosaic 仅提供双线性算法。Quad CFA Remosaic 支持：

- 仅重排：恢复标准 Bayer 站点排列，不改变颜色语义。
- 同色双线性重建：按相同 CFA 站点重建 DN，计算量和 CPU 使用率更高。

## 画布与界面

- 图像默认居中，可连续缩放、拖动，并始终保留一部分图像在视口内。
- 画布尺寸变化时保持当前缩放比例，并让原画布中心对应的图像位置继续位于新画布中心；只有用户主动执行“适应窗口”时才重新计算缩放。
- 未打开文件时主按钮使用 `Ctrl+O` 打开文件；打开文件后主按钮切换为低饱和红色的“关闭文件”，使用 `Ctrl+W` 释放文件映射并清空文件相关界面。RAW 参数、处理配置和应用设置保持不变，`Ctrl+O` 仍可直接选择其他文件。
- F11 使用系统原生无边框全屏覆盖当前显示器，隐藏 Windows 窗口边框和任务栏，同时保留软件自身的工具栏与状态栏；再次按 F11 恢复窗口。
- 滚轮缩放保持指针下的图像位置不变；状态栏也可输入缩放比例。
- 十字准星、坐标定位和高倍率像素值用于精确检查。
- 工具栏将 R/G/B 作为 Demosaic 右侧的并列子项；Demosaic 表示完整 RGB 结果，三个子项表示其重建单通道，不提供会回到 CFA 点阵的“全部通道”入口。
- ROI 是独立于统计窗口的主工具栏能力。“鼠标框选”和“坐标 ROI”是位于“适应窗口”左侧的两个互斥一级按钮，快捷键分别为 `R` 和 `Shift+R`；点击当前选中的按钮会取消 ROI 并恢复整帧。用户可在 RAW 强度或 CFA 点阵视图中持续使用右键拖动框选，也可输入以左上角 `(0, 0)` 为原点、包含起止端点的坐标；右键单击仍打开画布菜单。框选可从图像外的画布背景开始，越界端点自动钳制到图像边缘；新 ROI 替换旧 ROI。ROI 边界使用固定屏幕线宽并随图像缩放和平移。
- R/G/B 通道视图默认以对应通道颜色呈现重建强度，也可在侧边栏“画面呈现”中切换为“灰度（仅强度）”；该选择只影响屏幕着色，不改变重建 DN 或导出数据。
- 高倍率数值与当前显示语义一致：RAW、CFA 和 Remosaic 显示对应单点 DN；R/G/B 通道显示参与当前视图着色的重建通道 DN；Demosaic 按设置显示原始 DN 或三行插值 RGB。关闭像素值只隐藏文字并停止 DN 读取，像素网格边界继续显示以辅助位置定位；网格颜色可在“画面呈现”中即时调整并持久化。
- “画面呈现”常驻侧边栏，通道着色、高倍率数值及 Demosaic 数值策略均即时生效；不必打开或关闭设置对话框。
- 文件数据不足的像素可使用深色棋盘、浅色棋盘或自定义纯色显示。该偏好只影响预览，导出的缺失 DN 仍由导出窗口独立指定。
- 参数栏宽度可调，可放置于左侧或右侧；配置说明只在描述文字悬停超过 500 ms 后显示。
- 数值参数在回车、Tab 或失焦提交时会截断并限制到有效范围，同时将实际生效值写回输入框；空对齐值归一化为 `1`，其他空布局值归一化为 `0`。
- “图像格式”先选择存储方式；Unpacked8 和 MIPI packing 锁定固定位深，并自动隐藏不参与解码的字节序和有效位位置，Unpacked16 保留 8–16 bit 的完整容器配置。
- 全窗口禁用浏览器原生右键菜单；仅在已打开图像的画布内提供“图像统计…”和四项抓拍操作。持续框选模式下以移动阈值区分右键拖动和右键单击，完成框选不会误弹菜单。“当前画面”保留画布底色、缩放、平移及可见叠加层；“完整预览图”输出当前帧和显示模式的完整图像，不受画布视野影响且不包含画布 UI。两者均可保存为 PNG 或复制到剪贴板。
- “图像统计…”默认打开参数栏对侧的侧方停靠视图，也可切换到底部或摘出为与主窗口联动的独立窗口；侧方宽度最多约占参数栏之外工作区的三分之二，同时为画布保留最小观察空间。统计只读取当前 frame 的 L0 原始 CFA DN，自动使用当前 ROI 或整帧，支持 All/R/G/Gr/Gb/B（MONO 为 Y）摘要、精确 Histogram、Row/Column Profile。三类图表同时承载全部可用语义通道，并分别提供不会重建其他图表的曲线显隐开关；颜色沿用通道语义，线宽、虚线和明暗强度随主题保持可辨识，悬停只强调命中曲线而不淡化其他曲线。普通滚轮滚动统计页面，`Ctrl + 滚轮`缩放横轴，`Shift + 滚轮`缩放纵轴，组合按下时同步缩放双轴；横纵范围滑块、横轴起止坐标输入和 Y 轴重置继续保留。直方图两端留有少量显示边距，避免 0 DN 和满量程尖峰贴边。各图表高度可拖动分隔线独立调整，双击恢复当前布局默认值。ROI 或结果更新保留当前浏览位置；图像格式参数成功应用后保留统计页面和 ROI，但废弃旧结果、重置图表并按新 generation 计算，失败时回滚到最后有效描述符。这些单帧描述性结果不构成 EMVA 1288 合规测量。
- 统计视图当前不提供报告导出入口；中性 16:9 PNG 报告绘制代码保留为后续能力，待信息展示和版式重新确认后再接入保存流程。
- 诊断面板覆盖画布与参数栏，不改变画布尺寸或触发布局重排。
- 九套深浅主题同时控制界面与画布背景，并保持各自的色相、明暗、渐变或扁平风格；辅助文字和弱边框使用统一可读性基线，主题菜单在宽窗口使用双列、窄窗口使用单列；主题按钮只是菜单入口，不表示选中状态。
- 未打开文件时，画布中央的 RGGB 菱形标志保留四个 CFA 站点的基础色；菱形中心透明，光谱弧线沿边框持续巡游，并以适配深浅背景的呼吸光晕呈现空闲状态。打开文件后动画暂停，启用“减少动态效果”时恢复为静态标志。
- 语言菜单位于主题按钮左侧，使用地球图标作为入口；各语言始终以本语言名称列出，便于在陌生语言界面中自行切换。
- 界面支持跟随系统、English、简体中文、繁體中文、日本語、Español、Français 和 Deutsch。切换立即作用于当前窗口并自动保存，不需要重新启动。
- “帮助”入口当前保留占位；快捷键和关于信息已经可用。

## 导出定位

导出是当前文档参数和当前帧的确定性快照，不做批处理。打开导出窗口时冻结来源路径、文档世代、描述符、帧和处理参数；来源随后变化时，旧导出任务会被拒绝。

画布右键提供的 PNG 抓拍属于预览输出，不改变 RAW 数据，也不替代以下确定性 RAW 导出。完整预览图自动选择长边不超过 4096 px 的最高分辨率 LOD。

导出目标包括：

1. 原始 CFA：裁剪、去 padding、packing/unpacking、端序和位深转换。
2. Remosaic Bayer：仅 Quad CFA 可用，输出当前 Remosaic 处理结果。
3. Demosaic：彩色 CFA 可用，输出 RGB48 Interleaved。

范围可使用“起点 + 宽高”或“起点 + 包含式结束坐标”输入。缺失像素由用户指定 MONO 或 R/Gb/Gr/B 的输出 DN；界面负责联动约束和字段级错误提示。

## 已实现与后续边界

- [图像统计](IMAGE_STATISTICS.md)已实现单文件、当前帧、整帧或矩形 ROI 的首版能力。
- 图像统计不使用缩略瓦片、Remosaic/Demosaic 结果或屏幕着色；QCFA 底层按 16 个原子相位统计，首版界面合并显示 R/Gr/Gb/B。
- Remosaic/Demosaic 算法接口允许后续扩展，但当前不为算法数量牺牲界面清晰度。
- Remosaic 后的数据导出已经实现；通用批处理不属于查看器职责。
