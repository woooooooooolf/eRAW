### Changed

- 新增 Ubuntu 24.04 LTS x64 支持，同时提供 DEB 和 AppImage 两种分发格式。
- Windows x64 提供独立 EXE；所有发布文件均配套同名 `.sha256` 校验文件。
- 手动更新检查按运行平台和分发格式选择下载入口，项目网站增加 Linux 下载入口。

### Fixed

- 修正“跟随系统”的语言来源，读取桌面用户的 UI 语言，保留手动语言选择优先级。
- 回移修复 glib 字符串迭代器缺陷，并增加 Linux Debug、Release 回归及依赖源码完整性检查。

### Docs

- 更新七语帮助、随程序内嵌的 SKILL，以及 Linux 安装、构建和验证范围说明。
- 整理对话框模板、RAW 单元测试、公共构建脚本和测试分组，清理旧临时文件及未支持平台的图标。
- 统一后续 GitHub Release 的成果物命名、校验文件和简体中文更新说明格式。
