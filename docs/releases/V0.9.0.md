本版本汇总 V0.8.0 之后的手动更新检查功能和依赖维护更新。

### 新增：手动检查更新

- 关于页左下增加“检查更新”，仅点击时请求 GitHub Latest 的重定向响应头；启动、打开 RAW 或关于页均不自动联网检查。
- 校验官方仓库、稳定版本标签及适配的 Windows ZIP 入口；网络检查有超时和有限重定向，不读取发布 HTML 或下载正文。
- 关闭关于页不打断检查，重新打开保留进行中或最终结果；状态仅在当前进程有效。
- 下载由用户点击后交给系统浏览器处理，并补齐七语说明。

### 维护更新

- 更新 KaTeX、Vite、Tauri CLI、memmap2、reqwest、Tokio，以及前后端 dialog 插件和 rfd；同步第三方许可证清单。
- 本次不改变 RAW 解码、处理、统计或导出语义；CLI 参数与已有配置保持兼容。

### 验证与下载

- 执行 TypeScript/站点检查、前端与 Rust 测试、生产构建、独立 Windows EXE 构建及真实 EXE CLI/skill 测试；发布提交由 GitHub CI 和 CodeQL 验证。
- 未完整覆盖原生保存/取消、真实关于页下载点击及所有代理/浏览器组合；经维护者确认，按静态代码审核与已有自动化覆盖接受这些验证边界，不将其报告为完整交互验收。
- Windows x64 以单个 ZIP 提供，包含 EXE、SHA-256 清单、SPDX SBOM 与第三方许可证文本。
- 后续源码维护已回移修复 glib 字符串迭代器缺陷，见 [第三方依赖补丁](../DEPENDENCY_PATCHES.md)；V0.9.0 已发布的 Windows 产物保持不变。

完整变更：[V0.8.0…V0.9.0](https://github.com/woooooooooolf/eRAW/compare/V0.8.0...V0.9.0)。
